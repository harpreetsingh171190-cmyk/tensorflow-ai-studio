These are learning scaffolds. The transformer is not pretrained, the chatbot is not an LLM, no public cloud deployment has been performed, and model metrics must be generated by running training on a real dataset.

## Computer Vision AI Studio extension

- Streamlit image upload and top-k classification with pretrained ImageNet MobileNetV2 or a compatible local `.keras` classifier.
- Best-effort TensorFlow GPU detection, NVIDIA `nvidia-smi` metrics, and CPU/RAM snapshot metrics.
- Explicitly confirmed transfer-learning retraining from class-named image folders, with validation split, early stopping, model checkpoint, TensorBoard logs, and exported class labels/history.
- Training-history CSV/JSON explorer and downloadable prediction JSON.

Start with `streamlit run modern/ai_dashboard.py`. Install `requirements-modern.txt` and `requirements-vision.txt` first. See `modern/README.md` for setup and limitations. This is a local educational dashboard, not a secured production service or unattended retraining platform.

## AI Studio Extra Pack

- **Batch image inference:** analyze multiple uploaded images, retain per-file failures, and export results as CSV or JSON.
- **Dataset quality audit:** count images by class, summarize file extensions and size, detect unreadable files, and estimate class imbalance.
- **Training-time augmentation:** horizontal flips, small rotations, and zoom augmentation are applied only during training to help generalization.
- **Dashboard additions:** dedicated Batch Prediction and Dataset Audit tabs with downloadable reports.

These are local educational utilities. Batch inference uses the currently selected model; the default ImageNet model is not specialized for a user's own labels. Dataset audit recommendations are heuristics, not guarantees of dataset quality. Retraining still requires a labeled folder-per-class dataset and compatible TensorFlow installation.

## AI Studio Extra Feature Pack

- **Grad-CAM explainability:** optional heatmap for compatible custom convolutional `.keras` models. It is an approximate visual aid, not proof of causality.
- **Held-out model evaluation:** labeled folder evaluation with accuracy, per-class precision/recall/F1, and confusion matrix export. Use a separate test set not used during training or tuning.
- **TensorFlow Lite export:** convert a saved Keras model to `.tflite`, with optional dynamic-range quantization. Verify accuracy/latency on the target device before deployment.
- **Local prediction audit log:** stores UTC timestamp, filename, model, top label and score as JSONL; image bytes are not stored. Logs may still contain filenames or prediction metadata that users consider sensitive, so protect/delete them as needed.


## Added in AI Studio Ultimate Extra
- **Human-in-the-loop review queue:** save corrected labels and optional notes as local JSONL metadata. Corrections are not automatically fed into training; curate and validate labels first.
- **Prediction quality signals:** summarize confidence and top-label counts, then compare older/newer log windows using total-variation distance and confidence change. These are heuristic signals, not proof of model drift.
- **Dashboard tabs:** Human Review and Model Monitoring. Prediction records remain metadata-only; image bytes are not written to the log.


## AI Studio Ultimate Plus — additional operations pack

- **Reproducible dataset split manifest:** writes deterministic per-class train/validation/test file assignments to JSON with a configurable seed; it does not copy images. Group related frames/subjects manually to avoid leakage.
- **Inference benchmark:** measures repeated single-image latency (mean, median, p95, min/max) and approximate throughput for a saved Keras model after warm-up; hardware-dependent and excludes model loading/image decoding.
- **Deployment readiness checklist:** verifies model artifact presence/size and optional class-label JSON, and explicitly flags security and target-environment testing as manual requirements. It is not a production security certification.
- **Preprocessing consistency:** dashboard-trained MobileNetV2 models preprocess the dataset outside the saved model, matching the inference and benchmark paths.
- **Dashboard tabs:** Dataset Splits, Inference Benchmark, and Deployment Check.


## AI Studio Toolkit Pack (metrics, dataset safety, CLI)

- **Classification metrics (`modern/metrics.py`):** confusion matrix, per-class precision/recall/F1 with macro and weighted averages, top-k accuracy, expected calibration error with reliability bins, and multi-class Brier score. NumPy only.
- **Dataset safety (`modern/dataset_tools.py`):** `find_duplicate_images` groups byte-identical images and flags the same picture filed under different classes; `find_split_leakage` checks a split manifest for identical images landing in different splits. Exact duplicates only; near-duplicates need perceptual hashing.
- **Experiment helpers:** `read_experiments` and `best_experiment(metric, mode)` on top of the JSONL tracker.
- **Unified CLI (`python -m modern <command>`):** `profile`, `drift`, `split`, `duplicates`, `leakage`, `deploy-check`, `monitor`, `experiments`, `metrics`. JSON output, no TensorFlow needed.
- **Chatbot:** six extra topics (learning rate, epoch, data leakage, dropout, CNN, transfer learning).
- **API:** both FastAPI apps use the current `lifespan` mechanism instead of the deprecated `on_event`; `/health` now reports `model_load_error`.
- **Deployment:** `Dockerfile.modern` template for the API (untested here); the 2017 Dockerfiles are labelled legacy.

All of the above except the API and Dockerfile are covered by tests that run without TensorFlow. The Streamlit AI Studio has matching tabs (Dataset Safety, Metrics & Calibration, Experiments); these tabs were syntax-checked only and not run in a browser here.
