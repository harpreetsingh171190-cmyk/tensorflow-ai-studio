# Personalization notes

**Maintainer:** Harpreet Singh

This fork adds maintainer branding to the README and notebook metadata, plus a short attribution note at the top of each notebook.

The original license and upstream copyright notices are preserved. Existing datasets, plotted values, tables, and model outputs were intentionally not replaced wholesale: those values are part of each lesson's example and changing them without defining new experiments could make the notebooks inaccurate or stop them from working. To refresh a specific graph or dataset properly, define the new dataset/experiment and rerun the notebook to generate matching outputs.
